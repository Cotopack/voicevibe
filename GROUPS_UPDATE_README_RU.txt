VoiceVibe: восстановление участников старых групп

1. Замените файлы GitHub Pages из корня архива (index.html, app.js, styles.css и остальные ресурсы).
2. В Cloudflare Workers -> Edit code замените код на worker.js и нажмите Deploy. Секреты не изменяйте.
3. В Firebase Firestore -> Rules опубликуйте firestore.rules, если он еще не опубликован.
4. Создатель старой группы: Чаты -> группа -> Участники -> Добавить друзей в группу. Выберите друга. После записи UID в members группа появится у друга.
5. В группе должны быть реальные UID участников (не их ники). Если пользователь уже есть в members, а группа не видна, проверьте сообщение об ошибке загрузки групп в разделе чатов и версию Worker.

Нет доступа к живому Firebase, поэтому проверка между двумя аккаунтами возможна только после публикации.

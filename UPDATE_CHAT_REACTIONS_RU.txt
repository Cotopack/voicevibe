VoiceVibe — отметки в чате, реакции и фон репостов
Версия: chat-reactions-20261101-6

1. Замените index.html, app.js, styles.css в корне репозитория GitHub Pages.
   Копии в public также обновлены (для Firebase Hosting).
2. ОБЯЗАТЕЛЬНО: откройте Firebase Console → Firestore Database → Rules.
   Замените правила полным содержимым firestore.rules из этого архива.
   Нажмите Publish. Без этого реакции будут отклоняться сервером.
3. Дождитесь публикации GitHub Pages, затем обновите сайт.

Изменения:
- В репосте голубой градиент служит фоном вокруг оригинала.
  Исходное фото/видео и надписи остаются внутри рамки.
- Полученные отметки отображаются в личном чате с автором, по времени.
  Уже полученные отметки тоже подтягиваются из storyMentions.
  Есть кнопки просмотра и репоста; у истёкших историй кнопки скрыты.
- Если автор не в друзьях, в списке чатов появляется его уведомление.
  Для обычной переписки по-прежнему нужно добавить автора в друзья.
- Двойное быстрое нажатие на сообщение ставит ❤️ (не переключает её).
  Кнопка ☺ открывает ❤️ 👍 😂 🔥 😮 😢.
  Нажатие уже выбранной реакции снимает её. На аккаунт — одна реакция.
  Работает в личных и групповых чатах, сохраняется в Firestore.
- Правила разрешают менять только собственную реакцию, не чужие и не текст.
- При реакции чат не должен прыгать к последнему сообщению.

Проверено локально: синтаксис и 6 тестовых сценариев/наборов, включая
двойное касание, прокрутку, выбор/снятие реакций и сортировку отметок.
Проверки используют имитацию DOM и Firestore. Проверка на реальных
аккаунтах и Firestore Emulator не выполнялась.
Дополнительный tests/chat-reactions-browser.cjs требует Playwright
с установленным Chromium; в текущем окружении браузер недоступен.

# VoiceVibe — исправления и установка

Исправлены найденные ошибки:
- В личных чатах показываются последние 100 сообщений, в группах — последние 200, в хронологическом порядке. Загрузка более старых сообщений пока не реализована.
- Защита от смешивания личных чатов при быстром переключении и при смене аккаунта.
- Сохранение позиции прокрутки, если пользователь читает предыдущие сообщения личного чата.
- Текст сообщения и превью сохраняются одной атомарной операцией. Черновик другого открытого чата не очищается после завершения отправки.
- Принятие дружбы сохраняет обе стороны и удаляет заявку атомарно.
- Исправлена неопределённая storyRef при отправке уведомлений об отметках в истории.
- Мелодия прекращается при подключении собеседника и завершении звонка; добавлена повторная проверка входящего вызова после ожидания Firebase.
- Скрытые панели чатов больше не перекрывают другие мобильные вкладки.
- При выходе очищаются чаты, профили друзей, группы и истории; обработчики присутствия удаляются.
- Корневые файлы и public синхронизированы, включая firestore.rules.
- Из firebase.json убрана отсутствующая папка functions.
- Worker принимает запросы с GitHub Pages и обоих стандартных доменов Firebase Hosting.
- Исправлено сообщение об ограничении рефералов: действующее окно — 15 минут после регистрации.
- Усилены правила: для создания дружбы требуется входящая заявка; нельзя перезаписать чужую peerSession; ограничены поля изменений переписки и сообщений; реакции и ответы в историях разрешено добавлять только от своего имени.
- В Worker добавлен отсутствовавший GET /api/music. Каталог загружается из Cloudinary с прежними настройками CLOUDINARY_*. Дополнительно поддерживаются MUSIC_CATALOG_JSON или MUSIC_CATALOG_URL. Готовая музыка в архив не включена.

## Как обновить
1. Замените файлы сайта: для GitHub Pages используйте корень, для Firebase Hosting — public.
2. Опубликуйте корневой firestore.rules в Firebase Console → Firestore Database → Rules. Либо запустите DEPLOY_WINDOWS.bat для Firebase Hosting и правил.
3. Обновите код Cloudflare Worker файлом worker.js, сохранив существующие секреты, включая FIREBASE_SERVICE_ACCOUNT.
4. Сохраните существующие CLOUDINARY_CLOUD_NAME, CLOUDINARY_API_KEY и CLOUDINARY_API_SECRET. Каталог продолжит загружаться из Cloudinary. Дополнительные MUSIC_CATALOG_JSON / MUSIC_CATALOG_URL не обязательны.
5. Обновите страницу с очисткой кэша (Ctrl+F5).

## Проверки
Выполнены node --check для app.js и worker.js, проверка дубликатов HTML ID и совпадения файлов public с корнем.
Локальные проверки с имитацией DOM/Firebase: запуск модуля, выход из аккаунта, очистка звонка и группы. Проверки Worker: CORS для трёх доменов, отказ чужому источнику и запросу без авторизации.
Повторить из папки проекта: node tests/app-smoke.cjs и node tests/worker-smoke.cjs.

Ограничения проверки: полноценный браузер в среде недоступен. Реальные Firebase, Cloudinary, Cloudflare и WebRTC с двумя пользователями не проверялись; компиляция правил в эмуляторе Firebase не выполнялась. Перед публикацией для всех проверьте вход, принятие заявки, переписку, группы, отметки и звонки между двумя аккаунтами. Все возможные ошибки без таких проверок исключить нельзя.

## Обновление после получения старого Worker
Восстановлена прямая загрузка музыкального каталога из Cloudinary с пагинацией, фильтрацией аудиофайлов и удалением повторов. Используются прежние CLOUDINARY_CLOUD_NAME, CLOUDINARY_API_KEY и CLOUDINARY_API_SECRET. При наличии всех трёх настроек Cloudinary имеет приоритет перед MUSIC_CATALOG_JSON / MUSIC_CATALOG_URL. Создавать новый JSON-каталог не требуется. Существующие секреты не удаляйте. Проверена синтаксическая корректность и обработка каталога с имитацией ответов Cloudinary; реальный доступ к вашему аккаунту не проверялся.

## Исправление пустого экрана переписки
Стиль полноэкранного контейнера применялся ко всем дочерним div, включая пустой блок отметок в историях. Теперь он применяется только к .chat-shell, а уведомления скрываются на время переписки. Для исправления замените index.html и styles.css (в корне и public), затем обновите страницу Ctrl+F5. Worker и Rules для этого исправления обновлять не требуется. Проверена структура HTML и соответствие CSS-селекторов, полноценная визуальная проверка в браузере не выполнялась.

## Истории и последние чаты
Истёкшие истории удаляются из новых и просмотренных в открытом интерфейсе, проверка каждую секунду и при возврате на вкладку. Текст: цвет, размер, жирность, выравнивание; перенос за кнопку «Перетащить текст». Настройки и относительное положение сохраняются в textPosition; прежние истории отображаются как раньше. Чаты поднимаются после открытия и новых сообщений, история открытий сохраняется для аккаунта в текущем браузере. Исправлена сортировка нескольких групп. Обновить index.html, styles.css, app.js, в том числе public при Firebase Hosting. Новые Rules и Worker для этих изменений не нужны. Проверены синтаксис и локальные проверки запуска; визуальная проверка и публикация с настоящим Firebase не выполнялись.

## Перенос непосредственно за текст
Зажмите сам текст мышью или пальцем и ведите по экрану, не отпуская. Короткое нажатие открывает редактирование. Отдельная кнопка переноса скрыта. Исправлен скачок положения из-за CSS transform, текст ограничен границами редактора. Обновите index.html, styles.css и app.js. Проверены синтаксис, запуск и обработчики жеста с имитацией указателя; проверка на реальном телефоне не выполнялась.

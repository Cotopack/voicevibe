Истории: Aa добавляет новый текст, Готово сохраняет его как независимый блок. Можно добавить до 10 блоков, двигать одним пальцем и изменять размер двумя. Для хранения textLayers опубликуй файл VoiceVibe_Firestore_Rules_Multiple_Text.rules в Firebase Console -> Firestore -> Rules. Старые правила обязательно замени целиком. Проверить публикацию на настоящем Firebase не удалось.

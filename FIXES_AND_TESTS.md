# VoiceVibe — исправления и проверка

## Исправлено в этой сборке
- Устранена гонка при входящем голосовом вызове: обработчик `stream` теперь регистрируется до `answer()` и до асинхронных запросов Firestore. Это предотвращает пропуск события медиапотока при быстром подключении.
- Перед повторной инициализацией PeerJS уничтожается предыдущий экземпляр, чтобы не оставлять старое соединение сигнализации.
- В `firebase.json` добавлена явная привязка `firestore.rules`, чтобы правила Firestore можно было публиковать через Firebase CLI вместе с сайтом.
- Файлы приложения в корне и в `public/` синхронизированы.
- Файлы стилей не изменялись.

## Проверки, выполненные локально
- `node --check app.js` — успешно.
- Проверка HTML на повторяющиеся `id` — повторов нет.
- Проверка ссылок на локальные скрипты — отсутствующих файлов нет.
- Сверка корневых файлов и папки `public/` — совпадают.
- `styles.css` сохранён без изменений.

## Важно перед публикацией
Этот архив нельзя честно назвать полностью проверенным в production: реальный вход, Firestore, Cloudinary и голосовой WebRTC-звонок зависят от настроек внешних сервисов и теста на двух устройствах. Для запуска нужны доступ к Firebase-проекту `voicevibe-1b8c0`, включённые способы входа, опубликованные правила и существующий unsigned upload preset Cloudinary `voicevibe_upload`.

## Публикация на Windows
1. Установи Node.js LTS, затем Firebase CLI: `npm install -g firebase-tools`.
2. В терминале выполни `firebase login`.
3. Запусти `DEPLOY_WINDOWS.bat` из этой папки либо выполни:
   `firebase deploy --project voicevibe-1b8c0 --only hosting,firestore:rules`
4. Firebase CLI выведет URL сайта после успешной публикации.

Публикация затронет проект Firebase `voicevibe-1b8c0`; запускай её только если у тебя есть право администрировать этот проект.

Исправление отображения старых групп

1. Замените index.html и app.js на GitHub Pages (или загрузите все файлы проекта).
2. Проверьте, что в Cloudflare Worker опубликован worker.js из архива.
3. Убедитесь, что Firestore Rules опубликованы в Firebase.
4. Войдите на сайте под аккаунтом приглашённого пользователя и откройте Чаты.
5. Сообщение в Чатах теперь показывает ошибку сервера или отсутствие участия.

ВАЖНО: если старый документ группы в Firestore больше не содержит UID пользователя в поле members, ни запрос Firestore, ни сервер /my-groups не может показать такую группу этому человеку. Создатель должен восстановить участие; нельзя безопасно добавить произвольные старые группы по одному имени. Этот архив исправляет потерю найденных групп между асинхронными запросами, но не изменяет ваши данные на сервере.

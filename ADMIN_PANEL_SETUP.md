# Панель управления звёздами VoiceVibe

Панель предназначена только для UID разработчика. До настройки UID панель скрыта, а изменение ролей не разрешено.

## Что нужно настроить один раз

1. Открой Firebase Console → Authentication → Users.
2. Найди свой аккаунт и скопируй UID.
3. UID уже внесён в `app.js` и `firestore.rules`.
4. Загрузи обновлённые `index.html` и `app.js` в корень GitHub Pages (в ту папку, где находится текущий `index.html`).
5. В Firebase Console → Firestore Database → Rules вставь обновлённый `firestore.rules` и нажми Publish.
6. Обнови сайт через Ctrl+F5, открой вкладку «Профиль» — появится «Управление звёздами».

## Как использовать панель

- Введи часть уникального ника пользователя (минимум 2 символа).
- Нажми «Найти» или Enter.
- Нажми «Назначить админом», чтобы выдать синюю звезду.
- Нажми «Снять звезду», чтобы убрать роль администратора.
- Золотая звезда разработчика закреплена за UID, указанным в `DEVELOPER_UID`.

## Защита

Кнопка скрыта для остальных пользователей, а Firestore Rules дополнительно разрешают изменять документы `roles` только аккаунту с указанным UID. Не публикуйте UID сессии или пароль; Firebase UID не является паролем, но используйте его только для настройки проекта.

1. В GitHub Pages замени только app.js и app.html в папке, откуда публикуется сайт (обычно корень репозитория). Если используется Firebase Hosting из public, замени файлы в public.
2. Полный файл firestore.rules скопируй в Firebase Console > Firestore Database > Rules > Publish. GitHub сам правила не публикует.
3. Проверь ошибки на двух устройствах. Ошибка WebSocket к 0.peerjs.com означает внешнюю проблему с сигнализацией; исправление JS ограничивает повторы, но не гарантирует доступность сервера.
4. Предупреждение Tailwind CDN не причина сбоя поиска.

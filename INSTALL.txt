1. Replace app.js and app.html in GitHub repo folder that serves the site.
2. CRITICAL: paste the COMPLETE firestore.rules into Firebase Console -> Firestore Database -> Rules -> Publish. Uploading the rules file to GitHub does not activate it.
3. Refresh browser hard, sign in, check chats/groups.
4. Existing records must contain members (groups) or participants (conversations) as arrays including your Firebase UID. Rules cannot fix incomplete data.
5. Tailwind CDN warning is not fatal. Converting to compiled Tailwind requires a build process and is not included here.
6. Voice calls require accessible WebSocket peer server; not solved by Firestore rules.

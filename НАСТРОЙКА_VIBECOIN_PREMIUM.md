# Настройка Vibecoin, рефералов, групп и Premium

В проект добавлены Firebase Cloud Functions для операций, которые нельзя безопасно выполнять только в браузере: выдача реферального бонуса, покупка Premium и создание групп с проверкой дружбы.

## Что появится
- Групповые чаты: кнопка «Группа» во вкладке «Чаты», название и выбор друзей.
- Баланс Vibecoin в профиле.
- Персональный реферальный код и ссылка `?ref=КОД`.
- 10 Vibecoin пригласившему за нового зарегистрированного пользователя. Один UID может быть засчитан только один раз; код можно применить в течение 7 дней после регистрации. Самоприглашение запрещено.
- Premium за 50 Vibecoin на 30 дней; при повторной покупке оставшийся срок прибавляется к новому месяцу.
- Premium: загрузка банера профиля, обоев чата и собственных стикеров. Сохранённые стикеры не удаляются после истечения Premium; просмотр остаётся доступным, отправка — только при активном Premium.
- Коронка и фиолетовая подсветка ника активного Premium.
- Кнопка рекламы пока намеренно возвращает «Попробуйте позже — реклама пока не подключена» и не начисляет монеты.

## Важно перед публикацией

1. Установи Firebase CLI, выполни `firebase login` и убедись, что выбран проект `voicevibe-1b8c0` (`firebase use voicevibe-1b8c0`).
2. Для Cloud Functions Firebase может потребовать тариф Blaze с привязанным способом оплаты. Не включай платные сервисы, пока не согласуешь бюджет.
3. В корне проекта выполни `npm --prefix functions install`.
4. Разверни функции и правила:

   ```bash
   firebase deploy --only functions,firestore:rules,storage
   ```

5. Затем разверни сайт:

   ```bash
   firebase deploy --only hosting
   ```

6. Проверь Firebase Console → Authentication: разрешённые домены должны включать домен, на котором опубликован VoiceVibe.

## Защита рефералов

Бонусы выдаёт серверная функция через Firestore-транзакцию и документ `referralClaims/{uid}`. Повторный вызов для одного UID не выдаст награду повторно. Это не может гарантировать, что один реальный человек никогда не создаст другой аккаунт с другим адресом/провайдером; для более сильной защиты добавь Firebase App Check, антибот-проверку и серверный мониторинг.

## Проверка после развёртывания

- Войти в два отдельных аккаунта.
- В профиле первого открыть «Реферальная система» и скопировать ссылку.
- В чистом браузерном профиле перейти по ссылке и зарегистрировать новый аккаунт в течение 7 дней.
- Убедиться, что баланс пригласившего увеличился на 10; повторное применение кода не должно дать вторую награду.
- Проверить покупку Premium, истечение статуса через 30 дней, банер, обои, стикеры и групповой чат.

Перед развёртыванием функции и правила проверены статически, но удалённое развертывание в Firebase и реальные тесты с двумя аккаунтами из этой среды не выполнялись.
